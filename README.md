## 💻 Local Testing & Preview

To preview the website locally without any installation:

### Option 1: Python HTTP Server
```bash
# In the repository root:
python -m http.server 8080
# Visit http://localhost:8080 in your browser
```

### Option 2: Node.js / npx
```bash
npx serve .
```

## 🚀 GitHub Pages Deployment Instructions

Because this repository is named `khalilosam.github.io`, GitHub automatically treats it as the user site:

1. Push all files to the `main` branch of repository `khalilosam/khalilosam.github.io`.
2. Go to **Repository Settings** → **Pages**.
3. Under **Build and deployment**:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/ (root)`
4. Click **Save**.
5. Within 1-2 minutes, your website is live at:
   **`https://khalilosam.github.io/`**
